# DartClub – Vereins-App (Testversion)

Dart-App für den Verein: X01-Scorer, Trainingsspiele, Übungen, Trainingspläne, Minispiele, Turniere (K.-o., Doppel-K.-o., Gruppen, Schweizer System, Liga), Boards und Statistiken.

**Testversion:** Alle Daten werden nur lokal im Browser des jeweiligen Geräts gespeichert.

Zum Ausprobieren auf der Startseite „Demo starten“ antippen.
